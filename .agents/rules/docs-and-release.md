# Документация и релиз

## Двуязычные документы

Четыре файла ходят парами и обновляются в одном коммите:

| Английский | Русский |
|---|---|
| `README.md` | `README.ru.md` |
| `CHANGELOG.md` | `CHANGELOG.ru.md` |

`README.md` — то, что видит npm и GitHub по умолчанию. Вверху каждого файла стоит
переключатель языков; при переименовании или добавлении файла обнови ссылки во всех
четырёх.

Правки только в одной языковой версии не принимаются: расхождение доков хуже, чем
неидеальный перевод.

## Что требует правки README

- новая CLI-команда или флаг → раздел «Command line usage / Использование через консоль»;
- новое сочетание клавиш → таблица горячих клавиш (и `src/ui/components/modals/helpModal.js`);
- новая слэш-команда → раздел слэш-команд;
- новая тема → раздел тем и `.env.example`;
- новый файл или каталог верхнего уровня → дерево «Project structure»;
- изменение видимых строк интерфейса → раздел «Скриншоты».

## «Скриншоты»

Раздел «Скриншоты» — это ASCII-мокапы экранов, а не картинки. Подписи в них берутся
из кода (`helpModal.js`, `actionModal.js`, `fileModal.js`, `chatInfoModal.js`,
`statusBar.js`, `cli/formatters.js`): мокап, разошедшийся с интерфейсом, хуже, чем
его отсутствие.

В примерах — только вымышленные аккаунты, имена, ID и пути. Ни реального имени
владельца проекта, ни его контактов, ни его файловых путей в README быть не должно;
реальные публичные аккаунты (`@durov`, `BotFather`) и их настоящие ID — тоже не пример,
а чужие данные. Постоянный вымышленный состав: владелец `Alex Rivers (@alex_rivers)`,
собеседники `Sam Lee`, `Mia Novak`, `Nina Ivanova`, чаты `Tech Chat`, `Team Terminal`,
`News Channel`, бот `Deploy Bot`, пути вида `/Users/alex/Desktop`. Единственное место
с настоящим именем — строка копирайта в разделе «Лицензия».

Рамки выровнены по **терминальным колонкам**, а не по количеству символов: эмодзи
и любой символ с вариационным селектором `U+FE0F` занимают две колонки. Если правишь
мокап вручную, проверь, что у всех строк рамки одинаковая ширина, иначе она поедет.
Оба README содержат одни и те же мокапы: интерфейс русскоязычный, и английская
версия показывает его как есть.

Раздел «Безопасность» — не рекламный текст, а описание реальной модели угроз.
Менять его только вместе с фактическим изменением поведения.

## CHANGELOG

Формат — [Keep a Changelog](https://keepachangelog.com/), версионирование — SemVer.

- Любое заметное изменение попадает в секцию `## [Unreleased]` в обоих файлах
  под одну из рубрик: Added / Changed / Deprecated / Removed / Fixed / Security
  (в русской версии — Добавлено / Изменено / Устарело / Удалено / Исправлено /
  Безопасность).
- Формулировка — с точки зрения пользователя, а не коммита. «Добавлена отправка
  альбомов до 10 файлов», а не «рефакторинг sendFiles».
- Запись пишется сразу вместе с изменением, а не собирается перед релизом.

## Релиз

1. Перенести `[Unreleased]` в новую версию с датой в формате `ГГГГ-ММ-ДД`
   в обоих CHANGELOG, обновить ссылки сравнения внизу файла.
2. Поднять `version` в `package.json` по SemVer: ломающее изменение CLI-интерфейса
   или формата хранения — major; новая команда или возможность — minor; исправление — patch.
3. `npm test` и `node scripts/check-package.js` — оба зелёные.
4. `npm publish` (поле `prepublishOnly` прогонит тесты и проверку пакета само).

Версию в `package.json` нельзя менять без соответствующей записи в CHANGELOG.

## Язык

Код, комментарии, JSDoc, сообщения об ошибках и строки интерфейса — русский.
`README.md` и `CHANGELOG.md` — английский, `README.ru.md` и `CHANGELOG.ru.md` — русский.
Английская локализация интерфейса пока не сделана и заявлена в `[Unreleased]`;
до её появления не стоит вводить английские строки в UI вперемешку с русскими.
