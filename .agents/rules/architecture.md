# Архитектура и границы слоёв

## Три слоя

```
src/telegram/   протокол MTProto      → знает про teleproto, не знает про UI
src/state.js    состояние приложения  → EventEmitter, не знает ни про то, ни про другое
src/ui/         отрисовка             → знает про neo-blessed, не знает про MTProto
```

Связывает их единственный координатор — `src/ui/app.js`. Он подписывается на события
`state`, дёргает функции из `src/telegram/*` и раздаёт компонентам колбэки.

**Запрещено:**

- импортировать `teleproto` или `src/telegram/*` внутри `src/ui/components/**`;
- импортировать `neo-blessed` внутри `src/telegram/**`, `src/state.js`, `src/utils/**`;
- обращаться к `state` из компонентов — компонент получает данные аргументами метода
  и сообщает наружу через колбэки, переданные в фабрику.

Исключение — `src/telegram/formatter.js`: он превращает Telegram Entities в разметку
blessed, но делает это через строки-теги, не импортируя сам blessed.

## Состояние

`src/state.js` — единственный экземпляр `AppState extends EventEmitter`, экспортируется
как `export const state`. Мутация состояния всегда идёт через метод класса, который
в конце эмитит событие: `dialogs_updated`, `status_changed`, `filter_changed`,
`search_changed`, `active_chat_changed`, `messages_updated`, `typing_changed`.

Компоненты не подписываются на `state` сами. Подписки живут в `app.js`, оттуда же
вызываются методы перерисовки компонентов.

## Точки входа

- `bin/tuigram.js` — исполняемый файл npm-пакета, тонкая обёртка;
- `src/index.js` — роутер: разбирает `argv` и уводит либо в TUI (`startTui`),
  либо в одну из команд `src/cli/cliCommands.js` / `src/cli/init.js`;
- новая CLI-команда добавляется в `cliCommands.js` и регистрируется в `src/index.js`,
  а её описание — в оба README и в CHANGELOG.

## Конфигурация

`src/config.js` — единственный источник путей и настроек. Он же определяет, где лежат
`.env`, сессия и загрузки. Никакой другой модуль не вычисляет пути к пользовательским
данным самостоятельно и не читает `process.env` напрямую для настроек приложения.

## Зависимости

Рантайм-зависимостей шесть: `teleproto`, `neo-blessed`, `big-integer`, `colorette`,
`dotenv`, `input`. Новая зависимость добавляется только если её нельзя заменить
несколькими десятками строк на стандартной библиотеке Node.js — TUI-клиент должен
устанавливаться быстро и не тянуть транзитивное дерево.
