# Стиль кода

## Базовое

- Чистый ESM: `import` / `export`, расширение `.js` в путях указывается всегда
  (`./utils/time.js`, не `./utils/time`). `"type": "module"` в `package.json`.
- Отступ — 4 пробела. Двойные кавычки. Точка с запятой в конце инструкции.
- Node.js ≥ 18, встроенные модули импортируются с префиксом: `node:fs`, `node:path`,
  `node:os`, `node:events`, `node:assert/strict`.
- Сборки, транспиляции и TypeScript нет. Типы описываются в JSDoc.

## Именование

- Функции и переменные — `camelCase`; классы — `PascalCase`; константы модуля —
  `UPPER_SNAKE_CASE`.
- Фабрики UI-компонентов — `createChatList`, `createFileModal`: префикс `create` + имя.
- CLI-команды — `cmdSend`, `cmdDialogs`: префикс `cmd`.
- Приватные хелперы модуля не экспортируются и объявляются ниже экспортов, которые их
  используют, — файл читается сверху вниз.

## Комментарии и JSDoc

Каждая экспортируемая функция получает JSDoc **на русском языке** с `@param` и
`@returns`:

```js
/**
 * Разбирает аргументы `/sendfile`.
 * @param {string|string[]} rawArgs
 * @returns {{ paths: string[], caption: string }}
 */
export function parseSendFileArgs(rawArgs) {
```

Заголовок файла — блочный комментарий с одной-двумя строками о назначении модуля.

Комментарий внутри тела кода объясняет **почему**, а не «что». Так, в `theme.js`
комментарий рассказывает, почему цвета заданы hex-ом, а не что делает `buildTheme`.
Комментарий, пересказывающий следующую строку, не нужен.

## Обработка ошибок

- Ошибки, которые видит пользователь, формулируются по-русски и по существу:
  что случилось и что с этим делать.
- `catch {}` без переменной допустим только там, где сбой действительно не важен,
  и сопровождается комментарием с причиной (`// Игнорируем ошибку удаления`).
- Сетевые вызовы MTProto оборачиваются так, чтобы падение одного диалога не роняло
  весь интерфейс.

## Асинхронность

`async` / `await` везде; голых `.then()`-цепочек в коде нет. Долгие операции
(загрузка файла, история) должны быть прерываемыми и сообщать о прогрессе
через колбэк, а не через прямую запись в UI.
