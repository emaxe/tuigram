# TuiGram

Терминальный клиент Telegram (TUI + CLI) на Node.js поверх MTProto (`teleproto`).
Чистый ESM без сборки и транспиляции: то, что лежит в `src/`, — это то, что выполняется.

Публичная документация: [README.md](./README.md) (EN) и [README.ru.md](./README.ru.md) (RU).

## Мета

Перед добавлением или изменением правил, скиллов, инструкций -- прочитай скилл
`agents-conventions`.

## Быстрый старт для агента

```bash
npm install
npm test                        # юнит-тесты, без сети и без аккаунта
node scripts/check-package.js   # проверка содержимого будущего npm-пакета
node bin/tuigram.js paths       # какие пути и конфиг видит клиент
```

Запуск TUI (`npm start`) требует живой сессии Telegram и интерактивного терминала —
в автоматическом режиме он не проверяется. Проверяй изменения тестами и статическим
чтением кода, а не запуском интерфейса.

## Правила

### Архитектура и границы слоёв
Три слоя: `telegram/` (протокол), `state.js` (данные), `ui/` (отрисовка). Слои не
перепрыгивают друг через друга: компоненты не ходят в MTProto, модули `telegram/`
не знают про blessed. Вся связка — в `src/ui/app.js`.
[Подробности](.agents/rules/architecture.md)

### Стиль кода
ESM, 4 пробела, двойные кавычки, точки с запятой, JSDoc на русском языке над
экспортируемыми функциями. Комментарий объясняет «почему», а не «что».
[Подробности](.agents/rules/code-style.md)

### Интерфейс на neo-blessed
Цвета только hex-ом из активной темы, пользовательский текст — только через
`escapeBlessed()`, компонент создаётся фабрикой `createX(screen, theme, callbacks)`.
[Подробности](.agents/rules/ui-blessed.md)

### Тесты
Один файл `test/unit.test.js` на `node:assert/strict`, без фреймворка и без сети.
Новая чистая функция — новая проверка в соответствующей секции.
[Подробности](.agents/rules/testing.md)

### Секреты и пользовательские данные
`session.txt` = полный доступ к аккаунту. Не логировать, не коммитить, не класть
в пакет, писать только с правами `0600`. Ничего не писать внутрь каталога пакета.
[Подробности](.agents/rules/security.md)

### Документация и релиз
README и CHANGELOG существуют в двух языках и обновляются парами. Версия меняется
только вместе с записью в CHANGELOG.
[Подробности](.agents/rules/docs-and-release.md)
